# Layout Catalogue for 16:9 Presentation Decks

This catalogue provides 14 editorial layout archetypes (L1–L14) designed for 16:9 presentations, interior design quotations, lookbooks, proposals, and pitch decks formatted directly in self-contained HTML/CSS.

Every slide is designed for a standard 16:9 canvas (1280×720 px), keeping copy concise (maximum ~90 words per slide).

---

## Layout Reference Table

| # | Layout Name | Best Used For | Visual Direction / Image Specs |
|---|---|---|---|
| **L1** | **Cover** | Opening slide: hero photo, prominent title, project metadata in glass card | `cover` (16:9 full-bleed) |
| **L2** | **Contents / Agenda** | Table of contents: 6–10 numbered rows | `tall-1` (9:16 side photo) |
| **L3** | **Concept / Narrative** | Design philosophy: core narrative + pull-quote | `tall-1..3` (3 tall vertical strips) |
| **L4** | **Moodboard** | 5 core emotional keywords + 5 circular photo swatches | `mood-1..5` (1:1 circular swatches) |
| **L5** | **Palette** | Proportion breakdown (60/30/10) with colour codes & materials | Proportional horizontal colour track |
| **L6** | **Materials** | Material selection: 5 swatches with codes M1–M5 and specs | `mat-1..5` (1:1 circular textures) |
| **L7** | **Plan / Layout** | Functional floor plan with numbered room legend | Architectural layout plan |
| **L8** | **Atmosphere & Timeline** | Lifestyle narrative, 3–4 day-in-the-life moments | `room-2` (16:9 atmospheric shot) |
| **L9** | **Space Overview** | Half-slide space photo with numbered markers 01–05 + quotation table | `room-1` (4:5 perspective) |
| **L10**| **Product Detail ×2** | 2 items per slide: photo, specs, materials, unit price | `product-N` (4:3 studio shot) |
| **L11**| **Hero Product Feature** | 1 hero item: large title, itemized components table, feature photo | `product-N` (5:4 detailed shot) |
| **L12**| **Investment Summary** | Grouped cost subtotals, grand total, scope exclusions & payment terms | Clear table & prominent total |
| **L13**| **Process & Roadmap** | 3–5 sequential execution steps with timeline | `tall-2` (9:16 vertical process photo) |
| **L14**| **Closing & Contact** | Final slide: thank-you statement, brand philosophy, contact info | Reuses `cover` or atmospheric shot |

## Slide Rhythm & Composition

1. **Alternate Visual vs. Text Density:**
   - Pair photo-led slides (e.g. L1, L3, L8, L9, L14) with text/table-led slides (L2, L5, L10, L12) so no two heavy data tables sit back-to-back.
2. **Standard Quotation Sequence:**
   `Cover (L1) → Agenda (L2) → Concept (L3) → Materials (L6) → Space Details (L9/L10) → Investment Summary (L12) → Roadmap (L13) → Thank You (L14)`
3. **Word Count Budget:**
   - Keep copy under 90 words per slide. If an itemised quotation has 10+ items, split across two L9 or L10 slides.
4. **Editorial Hierarchy:**
   - **Eyebrow:** Uppercase category label (e.g., `SPACE 01 / 04`).
   - **Title:** Clear, prominent serif title.
   - **Content:** Hairline tables, bulleted specifications, or italicised pull-quotes.
   - **Art Direction Prompt:** Exact composition, lighting, and style instructions for each visual asset.
